# Daily Control

تطبيق محلي لإدارة المشاريع والمهام والمحادثات وأدوات الذكاء الاصطناعي.

## التشغيل المحلي

```bash
cd backend && npm install && npm start
cd ../frontend && npm install && npm run dev
```

انسخ `backend/.env.example` إلى `backend/.env` وأضف المفاتيح محليًا فقط. لا تضع أي مفتاح داخل Git أو داخل ملفات `backend/data/*.json`.

الواجهة تعمل افتراضيًا على `http://localhost:5173` والباك اند على `http://127.0.0.1:5000`.

## ملاحظات الأمان

- التطبيق محلي افتراضيًا، ولا يحتوي على نظام حسابات أو صلاحيات متعدد المستخدمين.
- هذه النسخة **مشددة**: الترمينال **قائمة بيضاء إجبارية** (`whitelist` يُفرض دائمًا)،
  حدود أضيق (مهلة وعدد وسائط أقل)، وسجل تدقيق `backend/data/terminal-audit.jsonl`.
- الأدوار: `مستخدم` للعمليات العادية، و`روت` للعمليات الحساسة
  (أوامر مميزة، تعديل قاعدة الأوامر، إيقاف السيرفر، `rm` المتكرر).
  استخدم `ROOT_PASSWORD_HASH` فقط هنا (ولّده بـ `node backend/scripts/gen-root-hash.js`)،
  وجلسة الروت قصيرة (10 دقائق افتراضيًا) — وهو مختلف عن `MASTER_KEY`.
- قاعدة الأوامر خارجية: `backend/data/terminal-commands.json` — تحديث حي بدون إيقاف النظام.
- استخدم `MASTER_KEY` طويلًا وعشوائيًا لتشفير مفاتيح المزودين وتوكنات GitHub الجديدة.
- بيانات المشاريع والمحادثات والمفاتيح تشغيلية ومُستثناة من Git.

## تشغيل بضغطة واحدة (لينكس)

```bash
bash install-shortcut.sh   # مرة واحدة: ينشئ أيقونة على سطح المكتب
```

بعدها اضغط الأيقونة: يشغّل السيرفر ويفتح المتصفح على `http://127.0.0.1:5000`. للإيقاف: كليك يمين على الأيقونة ← إيقاف.
